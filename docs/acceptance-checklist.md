## 성능 (기준 5)

CI 실행 **81** (`ios.yml`, 커밋 `cd6722a`, 2026-10-23) 의 `큰 견본으로 화면 시간 재기 (로그만)` 단계 — **Release 빌드**(2026-10-22 사용자 선택) · 시뮬레이터(iPhone 17) · 견본 사람 5,000명 + 8명 · 기록 50,000건 + 7건. 실행 넷의 값을 범위로 적었다. 괄호는 손보기 전(실행 80 · 같은 Release).
**목록 시간은 이제 첫 사람 줄이 실제로 그려진 때로 잰다** (실행 80 부터) — 그 전의 `목록 정렬 끝` 은 줄이 보이기 2초쯤 전이었다.
손본 것 (실행 80 측정으로 찾음): ① 목록 `ForEach` 바로 안의 `if` 때문에 SwiftUI 가 5,000줄을 미리 다 만들었다 → 줄마다 한 칸(`LiveRow`). ② 입력 상태 세기(5초 남짓)가 같은 자료 판으로 두 번 돌았다 → 도는 것을 기다린다.
**마무리 (2026-10-23 사용자 결정):** 목록 · 상세는 5,000명 기준 목표 밖이지만 이 값으로 기준 5 를 채운다 — 실제 쓰는 규모(수십~수백 명)에서는 체감이 없고, 더 줄이려면 목록이 사람을 나눠 읽게 바꿔야 한다(빌드 한두 개). 규모가 커지면 다시 연다.
CI 러너는 코어가 적은 가상 기계이고 실행마다 빠르기가 다르다(견본 채우기가 실행 80 은 12~16초, 81 은 9~10초) — 숫자는 흐름으로 본다.
