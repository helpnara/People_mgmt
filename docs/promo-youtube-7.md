# 유튜브 쇼츠 홍보 7 — 홈 화면에서 만나는 인연 (2026-11-07)

사용자 결정(2026-11-07): 일곱 번째 쇼츠 · 컨셉 **홈 화면에서 만나는 인연** — 1.1.9(App Store 2026-11-07)의 홈 화면 · 잠금 화면 위젯, 누르면 그 약속, 만나기 전에, 반복 약속. 링크는 넣지 않는다(첫 쇼츠와 같은 까닭 · `promo-youtube.md`).
기록 화면은 **지금 브랜치의 CI 스크린샷**(`48-briefing.png` 견본 정유진의 커피 약속 · 만나기 전에 / `50-repeat-detail.png` 견본 김하늘의 저녁 산책 · 매주 수요일 반복)이다. 위젯 · 잠금 화면 위젯은 CI 스크린샷이 없어 **위젯 코드(`Widget/SlowConnectionWidget.swift`)의 배치와 문구 그대로 그렸다** — 얼굴(사진이 없으면 첫 글자) · `D-3`(색은 이것 하나) · 제목 · `3일 후 오전 10:00 · 정유진` · 알약 둘 · 잎 하나. 날 · 시각은 견본 예정 자료(`SampleData.seedPlanned`)와 같다. 홈 화면의 다른 앱 칸은 이름 없는 흐린 네모다(다른 앱 이름 · 상표를 쓰지 않는다). 사람은 모두 지어낸 견본이다. 영상 파일은 저장소에 두지 않았다(`docs/promo/make_widget.py` 로 다시 만든다).
