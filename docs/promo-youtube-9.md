# 유튜브 쇼츠 홍보 9 — 명함 30장, 누가 누군지 기억나요? (2026-11-09)

사용자 결정(2026-11-09): 조회수 1회차 분석(`promo-youtube-stats.md`)을 바탕으로 아홉 번째 쇼츠를 만든다.
분석에서 가져온 것:
- 가장 잘된 쇼츠 1(첫 인연 · 어떻게 알게 되었는지 · 1.1천회)의 주제를 다시 쓴다.
- 첫 2초는 **숫자 하나 + 질문**(`30장` · `누가 누군지 기억나요?`)으로 연다.
- 기능 이름(명함 여러 장 등록)은 셋째 장면부터 나온다.
- 제목은 한글로 쓴다.

기능은 1.1.9(App Store 2026-11-07)의 명함 여러 장 등록(이슈 103)이다. 첫 인연과 검색(알게 된 경로 일치)으로 이어진다. 링크는 넣지 않는다(첫 쇼츠와 같은 까닭 · `promo-youtube.md`).

**앱 화면**
- `52-card-batch.png` — CI 의 `-cardBatch` 견본 명함 세 장(한서연 · 오지훈 · 남궁별).
- 나머지 장면은 앱 문구 그대로 다시 그렸다.
  - `CardBatchView.commonSections`: `모두에게 · 알게 된 경로`, 칩 `직장 … 동호회·모임 · 직접 입력`, 바닥글, `모두에게 · 처음 만난 날`, `처음 만난 날 넣기`, `n명 저장`.
  - `PersonDetailView.firstEncounterSection`: `첫 인연`, 날짜, 메모.
  - `SearchMatcher`: `알게 된 경로 일치`.

사람 · 소속 · 행사(`2026 북페어`)는 모두 지어낸 견본이다. 영상 파일은 저장소에 두지 않았다(`docs/promo/make_cards.py` 로 다시 만든다).

## 올릴 때

- **표지:** `30장` 이 다 뜬 첫 장면(2초 무렵)을 고른다. 첫 2초 글과 표지가 같아야 제목 · 표지 · 첫 장면이 한 질문으로 이어진다.
- **올리는 날:** 다른 앱(느린 부자 · 느린 여백)의 쇼츠를 올리지 않은 날 하나만 올린다. 조회수 분석 4번의 가설을 시험하는 셈이다.
- **시청자층:** 아동용 아님.
