# 유튜브 쇼츠 홍보 17 — 송년회 12명, 작년엔 무슨 얘기 했더라? (2026-11-27 · **2026-11-28 업로드 완료 · 2026-12-04(금) 12:00(한국 시간) 게시 예약(사용자)**)

- 일정표 12-04(금) 12:00 칸 · **돈 · 시간 다리 2주 시험의 둘째 주** 인연 편 — 첫 물음에 사람 수(12명) · 시간(3시간 나눈 이야기).
- 앞 편과 겹치지 않게 **한 기록에 여러 사람(N:M) · 기록 틀**을 보인다 — 14편(찾기 · 근거 줄) · 16편(사람 화면 · 기억할 것 · #선물)과 다른 자리.
- 앱의 반복(`RepeatRule`)은 매주 · 2주마다 · 매달뿐이라 **해마다 하는 송년회는 반복이 아니라 기록 틀**로 잇는다(없는 기능을 팔지 않는다 · CLAUDE.md §7).
- **0초 장면에 질문 글이 이미 다 떠 있다** · 설명과 고정 댓글 **모두 App Store 링크**.

**앱 화면** — 모두 앱 문구 그대로 다시 그렸다.
- 기록 상세(`RecordDetailView`, screenshots/09 의 꼴) — 유형 아이콘 · `친목 · 2025년 12월 19일` · 제목 · 장소, `함께한 사람` 줄, `메모`.
- 사람 화면 타임라인 줄(`TimelineRow`) — 같은 기록이 함께한 사람마다 보인다(기록은 한 번만 저장 · ADR-0003).
- 기록 추가(`RecordEditView`, screenshots/51 의 꼴) — 맨 위 `틀` 칩(**새 기록이고 저장한 틀이 있을 때만** 보인다) · 안내 `자주 쓰는 기록 모양을 누르면 유형 · 제목 · 장소 · 태그 · 함께한 사람이 채워집니다. 날짜 · 메모는 그대로입니다.` ·
  `함께한 사람` 줄 요약 `이도윤, 강태오 외 10명`(participantSummary — 앞의 두 이름 + 외 n명). 틀을 누르면 그 화면을 연 사람이 맨 앞에 남고 틀의 사람이 가나다순으로 붙는다(`TemplateStore.fill`).
- 틀 만들기 — 기록 수정 맨 아래 `이 기록을 틀로 저장` · 안내 `설정 → 기록 틀에서 이름을 바꾸거나 뺄 수 있습니다.`

사람 열두 명 · 기록 · 메모는 모두 영상용으로 지어냈다. 영상 파일은 저장소에 두지 않았다(`docs/promo/make_party.py` 로 다시 만든다).
