# 영상 워터마크 후보 (2026-11-24)

유튜브 영상 워터마크 규격 — **정사각 · 150×150 이상 · 1MB 미만**(YouTube 고객센터 *채널 브랜딩 관리*). 넣는 곳: YouTube Studio → 맞춤설정 → 브랜딩 → 동영상 워터마크.

| 파일 | 모양 | 작게 떴을 때 |
|---|---|---|
| `wm-a.png` | 크림 원 · 금 테두리 · 명조 `느린 / 나눔` | 밝음 · 어두움 모두 읽힘 |
| `wm-b.png` | 먹색 원 · 크림 `느린` · 금 `나눔` | 밝은 화면에서 좋음, 짙은 초록 위에서 묻힘 |
| `wm-c.png` | 투명 · 흰 글씨 · 흰 테두리 | 밝은 화면에서 거의 안 보임 |
| `wm-d.png` | 크림 원 · 새싹 + 작은 `느린 나눔` | 글씨가 작아 안 읽힘 |
| `wm-e.png` | 크림 원 · 금 테두리 · 새싹만 | 밝음 · 어두움 모두 또렷 |

600×600 PNG(투명 바탕). 다시 만들기: `node docs/promo/watermark/shot.mjs` (글꼴은 `../banner/fonts`). `preview.png` 는 위 크기 · 아래 작게 띄운 모습.
