# 유튜브 쇼츠 홍보 13 — 가까운 사람 10명, 처음 만난 날 다 기억하나요? (2026-11-18 · **2026-11-18 업로드 완료 · 2026-11-23(월) 12:00(한국 시간) 게시 예약(사용자)**)

사용자 결정(2026-11-18):
- 다음 1주 일정(`promo-youtube-stats.md` 의 `다음 1주 게시 일정`)의 **인연 13편 · 낮 12:00 공개** 칸.
- 주제는 **처음 만난 날** — 일정표의 후보 `올해 처음 만난 사람, 몇 명?` 은 쇼츠 4(`한 해 돌아보기` · 50회)와 화면 · 이야기가 겹쳐 바꿨다.
  2회차 분석 6번 — 같은 이야기를 되풀이한 편(여백 `앱을 지워도 노트가 남나요?`)이 5회였다.
- 가장 잘된 쇼츠 1(`이 사람, 어디서 만났더라?` · 1,181회)과 같은 결 — **처음 만남** — 을 새 장면으로. 사람에 대한 질문 + 숫자(분석 2 · 7번).
- **0초 장면에 질문 글이 이미 다 떠 있다** · 설명과 고정 댓글 **모두 App Store 링크**(`promo/README.md` 문안 규칙).

기능은 모두 1.1.12 까지 출시된 것이다 — 첫 인연(처음 만난 날짜 · 정밀도 · 계기) · 타임라인의 시작점 · 입력 상태 · 처음 만난 날 채우기 · 알게 된 지 n주년 알림.

**앱 화면**
- `20-network-readiness.png` — 내 인맥 → 입력 상태의 `올해 처음 만남` 칸: `처음 만난 날을 적은 사람 5명 / 8명` · `처음 만난 날이 빈 사람 3명`.
- `31-fill-first-met.png` — `처음 만난 날이 빈 사람` 목록 · 줄마다 `처음 만난 날 채우기`(누르면 바로 편집).
- 나머지는 앱 문구 그대로 다시 그렸다.
  - `PersonEditView` 의 `첫 인연` 칸 — `처음 만난 날짜` 스위치 · 정밀도 `날짜까지 · 월까지 · 연도만`(`DatePrecision.label`) · `날짜` · `어떤 계기로 알게 되었나요?`.
  - `PersonDetailView` 타임라인 맨 아래 — 깃발(`flag`) · `2019년 3월` · `시작점 — 처음 만남`.
  - `SettingsView` 의 알림 칸(차례 그대로) — `알게 된 지 n주년` · 기본은 모두 꺼짐.
  - `Core.ReminderPlanner` 의 알림 — 제목 `김하늘 님과 알게 된 지 7년이 되었습니다` · 본문 `처음 만난 날 2019년 3월 14일` · 기본 시각 오전 9:00.
    **n주년은 날짜까지 적은 사람만 온다**(`Reminders.knowsFirstMetDay`) — 그래서 화면 글이 `날짜까지 적었다면` 이다.

사람은 모두 견본(`SampleData`)의 지어낸 이름이다. 영상 파일은 저장소에 두지 않았다(`docs/promo/make_firstmet.py` 로 다시 만든다).
