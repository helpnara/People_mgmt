# 느린 인연 도움말 · 문의

느린 인연은 사람과의 인연을 기록하는 개인용 앱입니다. 회원가입이 없고, 자료는 기기와 (동기화를 켜면) 내 iCloud 의 비공개 영역에만 있습니다. 개발자는 기록하신 자료를 볼 수 없습니다.

## 자주 묻는 것

### 처음인데 무엇부터 보면 되나요?

- 사람이 하나도 없을 때 첫 화면의 **견본으로 둘러보기** 를 누르면 지어낸 사람과 기록으로 앱을 먼저 볼 수 있습니다. 견본은 끝내면 사라지고 내 자료와 섞이지 않습니다.
- 사람은 이름만 적어도 저장됩니다. 사람 화면의 **기록 추가** 로 함께한 시간을 적으면 타임라인과 내 인맥이 채워집니다.

### 아이폰과 아이패드에서 같은 자료를 보려면?

- 두 기기가 같은 Apple 계정으로 iCloud 에 로그인되어 있고, 앱의 **설정 → iCloud 동기화** 가 켜져 있으면 됩니다(처음에는 켜져 있습니다).
- 동기화를 켜고 끄는 것은 앱을 완전히 닫았다가 다시 열 때 적용됩니다. 설정의 iCloud 동기화 칸에서 마지막으로 주고받은 때를 볼 수 있습니다.

### 기기를 바꾸거나 앱을 다시 설치할 때는?

- iCloud 동기화를 켜 두었다면 같은 Apple 계정으로 로그인한 새 기기에서 자료가 내려옵니다.
- 동기화를 쓰지 않는다면 **설정 → 백업 파일 만들기** 로 파일을 만들어 파일 앱이나 iCloud Drive 에 저장해 두세요. 새 기기에서 **설정 → 백업에서 복원** 으로 되살립니다. 복원은 앱이 비어 있고 iCloud 동기화를 끈 상태에서만 합니다.

### 앱을 잠글 수 있나요?

- **설정 → 앱 잠금** 을 켜면 앱을 열 때와 다른 앱에 갔다 돌아올 때 얼굴 인식이나 기기 암호로 확인합니다. 기본은 꺼져 있습니다.

### 알림이 오지 않아요.

- **설정 → 알림** 에서 생일 · 알게 된 지 n주년 · 연락 주기를 켜야 합니다(기본은 모두 꺼짐). 기기의 설정 앱 → 알림 → 느린 인연에서 알림이 허용되어 있는지도 확인해 주세요.

### 지운 사람을 되살릴 수 있나요?

- 사람이나 기록을 지운 뒤 5초 동안 화면 아래의 되돌리기를 누르면 되살아납니다. 그 뒤에는 백업 파일에서만 되살릴 수 있습니다.

### 모든 자료를 지우려면?

- **설정 → 자료 지우기 → 모든 자료 지우기** 를 누르고 두 번 확인하면 사람 · 기록 · 아는 사이 · 명함과 사람 사진이 모두 지워집니다. 동기화가 켜져 있으면 같은 Apple 계정의 다른 기기와 iCloud 에서도 지워집니다. 설정은 그대로 남습니다.
- 앱을 지우면 기기 안의 자료도 함께 지워집니다. iCloud 에 올라간 자료는 기기의 설정 → 사용자 이름 → iCloud → 저장 공간 관리에서 지울 수 있습니다.
