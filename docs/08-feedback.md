형식: `번호 · 상태 · 제목 · (발견 빌드) · 내용` — 상태는 🔴 급함 · 🟡 고칠 것 · 🔵 알아볼 것 · 🟢 해결 · 🟠 뒤엎음(대신하는 항목 번호를 적는다).

**이슈는 사용자가 실기기 · 스크린샷에서 발견하고, 세션이 여기에 번호로 적는다.** 5개 내외 모이면 "착수할까요?" 를 묻는다.
