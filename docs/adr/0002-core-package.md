# ADR-0002 · 순수 로직은 `Packages/Core` — Foundation 만

**상태**: 채택 · 2026-10-17

## 맥락

개발 환경에 맥이 없다. 원격 세션은 리눅스라 SwiftUI · SwiftData 를 컴파일할 수 없고, Swift 툴체인조차 설치할 수 없다. 컴파일 못 하는 코드에 손으로 기댓값을 적으면 테스트가 버그를 승인한다 (느린 부자 · 느린 여백 공통 교훈).

## 결정

- 화면 · 저장소와 무관한 셈은 전부 로컬 SPM 패키지 `Core` 에 둔다: 글자 정리(NFC · 소문자) · 태그 정리 · 검색어 파싱과 일치 · 이름 정렬 · 표시명 · 입력 검증 · 조사(을/를) · 날짜 정오 정규화 · 선택지 목록.
- `Core` 는 **Foundation 만** import 한다. SwiftUI · SwiftData · UIKit 금지.
- 기댓값은 `Tools/golden/generate.py` 가 설계서만 보고 파이썬으로 다시 구현해 JSON 으로 적고, `GoldenTests` 가 그것을 읽는다. CI 리눅스 컨테이너(`swift:6.1-noble`)에서 `swift test` 가 돈다.
- 앱은 저장소 객체를 **값 구조체**(`SearchablePerson`)로 베껴 Core 에 넘긴다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 뷰모델 안에서 직접 계산 | 시뮬레이터 없이 테스트 불가. 원격 세션에서 검증할 수 있는 범위가 사라진다 |
| 기댓값을 손으로 적기 | 컴파일 못 하는 환경에서는 테스트가 버그를 승인한다 |

## 결과

- 정렬에 로케일 비교(`localizedStandardCompare`)를 쓰지 않는다 — 파이썬 정답표와 같은 답이 나와야 하므로 NFC · 소문자 열쇠의 유니코드 차례를 쓴다. 한글 음절은 그 차례가 가나다순이다. 영문이 한글 앞에 온다.
- 글자 수(`count`)는 Swift 의 자소 단위와 파이썬의 코드포인트 단위가 다를 수 있다. 정답표의 사례는 NFC 한글 · 라틴으로 한정한다. 이모지 결합 문자는 길이 제한에서 1~2 글자 차이가 날 수 있고, 이는 받아들인다.
